# Blog resources

Data and supporting material for articles on [Sadat Nazrul's Medium blog](https://medium.com/@sadatnazrul).

## Repository structure

```text
articles/
└── <topic>/
    ├── README.md
    └── data/
```

Resources are grouped by topic under [`articles/`](articles/). Each topic contains its data and any relevant notes in its own README.

Add new resources to the appropriate topic folder, or create a new one. Keep existing file paths stable so links from published articles continue to work.
